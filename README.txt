Ақ Киіз — лендинг

Как открыть: распакуйте архив и откройте index.html в браузере.

Как поменять номера:
  откройте js/main.js — в самом верху блок CONFIG:
    whatsapp: "77000000000"   ← номер WhatsApp (только цифры, с 7 в начале)
    phones: [...]             ← телефоны для звонков
    waMessage                 ← текст, который появится в WhatsApp
  Номера автоматически подставятся во все кнопки на сайте.

Название «Ақ Киіз» можно заменить в index.html (поиск по тексту).
